# Security policy

## Supported versions

Only the latest commit on `main` is supported. No response-time or fix-time
SLA is guaranteed.

## Reporting a vulnerability

Do not open a public issue or disclose a vulnerability in public discussion.
Use GitHub Private Vulnerability Reporting for the repository that hosts this
source. Include a reproduction, impact, affected commit SHA, and attack
preconditions. Redact credentials, tokens, and private repository details.

Reports outside GitHub Private Vulnerability Reporting, including support
requests, may not receive a response.
